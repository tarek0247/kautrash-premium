\## 🚀 Quick Start



```bash

\# Clone repository

git clone https://github.com/tarek0247/kautrash-premium.git

cd kautrash-premium



\# Start with Docker

docker-compose up -d



\# Or manual setup

cd backend \&\& npm install \&\& npm run dev

\# In another terminal

cd frontend \&\& npm install \&\& npm run dev

```
